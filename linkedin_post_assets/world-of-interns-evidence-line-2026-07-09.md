# World of Interns LinkedIn Post - 2026-07-09

## Topic

Thursday Recruiter Insight - add an evidence line under each project so recruiters can scan proof faster.

## Caption

A recruiter does not read your project section like a college examiner.

They are not checking whether the project sounds impressive.

They are usually checking one thing:

"Can I quickly see proof that this student can do the work?"

That is why a project with only a title and tech stack often gets skipped.

Example:

Expense Tracker App
React, Firebase, CSS

Useful, but still incomplete.

Add one evidence line:

"Built an expense tracker that helped 12 classmates split hostel costs and compare weekly spending."

Now the recruiter can scan:

- what you built
- who used it
- what problem it solved
- which skill it proves

The project did not become bigger.

It became easier to trust.

Before you send your next application, check your top 2 projects.

Do they have evidence lines, or only tool names?
