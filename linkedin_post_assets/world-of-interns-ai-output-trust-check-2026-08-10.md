```text
AI can help you write faster.

It cannot decide what is true for you.

Before you paste an AI-written resume bullet, email, LinkedIn message, or project summary, run one small trust check.

Ask four questions:

1. Source
Where did this point come from?

If the answer is "the tool guessed", do not use it as a fact.

2. Numbers
Is every metric real?

Do not keep a percentage, user count, ranking, or result unless you can explain it.

3. Fit
Does this match the role you are applying for?

A polished sentence is still weak if it answers the wrong job description.

4. Voice
Would you say this in an interview?

If it sounds bigger than your actual work, rewrite it in plain language.

The best use of AI is not making your profile louder.

It is making your real work clearer.

Use the tool.
Then verify like a human.

What is one AI-written line you would double-check before sending?
```
