## Caption

Your resume bullet should survive one follow-up question.

AI can help, but only if you give it proof first.

Before asking for better wording, paste three things:

1. the raw project note
2. the exact internship description
3. the result you can explain without guessing

Then ask:

"Turn this into 3 resume bullets. Mark every claim that needs proof."

Delete any bullet you cannot defend in an interview.

Keep the bullet that shows action, tool, and outcome:

"Built a React dashboard that reduced manual tracking from 2 hours to 20 minutes."

If there is no number, use scope:

"Built a React dashboard used by a 5-member project team."

AI is useful for structure.
It should not invent your experience.
