## Caption

Many students finish a class task, close the laptop, and move on.

Then, a few weeks later, they struggle to explain what they actually learned.

Try a two-sentence reflection note after every project, assignment, or internship task.

Sentence 1:
What changed because of the work?

Sentence 2:
What would you improve if you had one more hour?

That is enough.

You do not need a long journal.
You need a small record while the details are still fresh.

This habit turns "I built a dashboard" into something clearer:

"I built a dashboard that helped compare weekly application progress.
If I had one more hour, I would add a filter for role type because the first version made every opportunity look the same."

That second version is easier to discuss in an interview.
It shows outcome, judgment, and the next improvement.

Pick one task you completed this week.
Write the two sentences before you forget the details.

Which task would you reflect on first?
