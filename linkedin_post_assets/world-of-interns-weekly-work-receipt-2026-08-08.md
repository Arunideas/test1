## Caption

Many students do real work during a project, internship, or club role.

Then, when it is time to update the resume or answer an interview question, the details are gone.

A small habit fixes this: keep a weekly work receipt.

At the end of each week, write four plain lines:

1. One task I touched
2. One decision I made
3. One result, screenshot, number, or link I can save
4. One lesson I can explain clearly

This is not journaling for motivation.

It is evidence capture.

After a few weeks, you have better resume bullets, clearer project explanations, and more specific interview examples.

If you are working on anything this week, save the receipt before the memory fades.

What would you add?
