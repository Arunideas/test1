Topic: Friday Future Skill - source-note verification for AI-assisted student work.

## Caption

AI output is not finished work until you can trace it.

A useful future skill for students is not "using AI faster."

It is keeping source notes while you use AI.

Before you paste an answer into an assignment, project, resume point, or case study, ask three things:

1. Which line came from a real source?
2. Which line is my own judgement?
3. Which line still needs proof?

This habit changes the work.

You stop defending vague output.
You start explaining decisions.
You can show what you checked, what you rejected, and what you changed.

That matters in interviews too.

If someone asks, "How did you reach this answer?", the best response is not "I used AI."

It is:

"I compared the output with the source, kept this part, removed that assumption, and tested it against one example."

That is the difference between using a tool and owning the work.

What is one small check you use before trusting an AI answer?
