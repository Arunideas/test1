# World of Interns LinkedIn Post

## Topic
Tuesday Resume Review - project section proof check for freshers.

## Caption
Your project section is not a tech stack list.

A recruiter does not shortlist you because one line says React, Node, MongoDB.

They shortlist when the project proves you can solve a small problem clearly.

Try this test:

1. What problem did you choose?
2. What did you build?
3. What changed after it worked?

Weak:
"Built food delivery app using MERN."

Stronger:
"Built a food ordering flow that reduced checkout steps from 6 to 3 and added order status tracking for users."

Even if the project is academic, show the decision you made.

What feature mattered?
What trade-off did you handle?
What result can someone verify?

Before you apply today, rewrite one project bullet so it answers:

Problem -> Action -> Proof.

Which project on your resume needs this cleanup first?
