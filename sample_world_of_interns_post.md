## Caption

Prompt of the Week

One weak resume line can hide six months of real work.

A final-year engineering student wrote this:

"Worked on inventory project using Python."

Nothing is technically wrong with it. But a recruiter only sees a tool. They do not know the problem, who used it, or what changed after the project shipped.

The better version was:

"Built a Python inventory tracker that reduced manual stock checks for a 120-student lab."

Same project. Same student. Clearer proof.

Copy-paste prompt:

"Rewrite this resume bullet using problem, tool, action, and result. Keep it under 22 words. Make it specific, honest, and easy for a recruiter to scan. If a metric is missing, suggest where I should add one instead of inventing it."

Takeaway: AI is useful for resumes when you give it constraints and then verify every claim.

Which line should you fix first?

[ ] Project line with no result  
[ ] Skill line with no proof  
[ ] Internship line with vague work
